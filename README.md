\# Site Operations Dashboard



Full-stack dashboard for managing sites and tracking installation activities.



\## Tech Stack



\- \*\*Frontend\*\*: React 18 + Vite + React Router

\- \*\*Backend\*\*: Node.js + Express + Joi

\- \*\*Database\*\*: PostgreSQL 18

\- \*\*Logging\*\*: winston

\- \*\*Deployment\*\*: Azure (App Service + Static Web Apps + Azure Database for PostgreSQL)
